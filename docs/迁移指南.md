# 迁移指南

## 资产迁移

1. 迁移资产
    - `src/dexjoco/assets/common`：公用资产，如桌子、墙壁贴图
    - `src/dexjoco/assets/robots`：机器人模型
    - `src/dexjoco/assets/tasks/<task>`：任务场景专用模型

2. 修改路径
    - `include` 用相对自身的路径
    - `compiler` 的 `meshdir` 和 `texturedir` 指向 `assets` 根目录，且只在环境入口 XML 中配置。例如，`src/dexjoco/assets/tasks/water_plant/water_plant.xml`：
      ```xml
      <compiler angle="radian" eulerseq="zyx" autolimits="true"
                meshdir="../../" texturedir="../../" />
      ```
    - mesh 和 texture 的 `file` 属性都相对 `assets` 根目录
